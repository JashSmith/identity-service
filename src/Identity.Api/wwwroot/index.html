Identity & Access Control Architecture

System Operational
1. User Identity & Provisioning
Users are defined in Keycloak with credential validation, business role mapping, and dynamic attribute scope restrictions stored on the user profile.
2. Business Roles & Groups
Composite business roles (e.g., Manager, Accountant) are modeled as Keycloak groups bundling granular service permissions.
3. Dynamic Attribute Scopes
Scope dimensions (e.g., branch, region, cost center) are registered in iam-scope-registry and assigned with specific authorized values per user.
4. Token Claims & Data Filtering
Scoped permissions propagate into authz.scope.<key> claims in minted JWT tokens, allowing microservices to enforce row-level filtering.
