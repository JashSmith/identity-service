Platform Architecture

Operational

• Keycloak Identity Provider: Central source of truth for users, credentials, realm roles, and group memberships.

• Business Roles: Modeled as Keycloak groups (e.g. Manager, Accountant, Clerk) with aggregated fine-grained client roles.

• Runtime Scope Attributes: Scoped attributes stored on user profiles in Keycloak attribute iam.scoped_access and projected into the JWT claim iam_access.

• Token Revocation: Instant session termination via Keycloak Admin API + Redis distributed cache eviction.

مدیریت و سوئیچ بین دیتابیس‌ها (Docker Compose Switch)
شما می‌توانید به راحتی بین ۳ دیتابیس سوئیچ کنید. نیازی به بیلد مجدد ایمیج Keycloak نیست؛ هر ۳ درایور به صورت یکپارچه پشتیبانی می‌شوند. کافیست متغیر DB_PROVIDER را در فایل deploy/.env تغییر دهید یا از پروفایل‌های داکر استفاده کنید:
۱. اجرای با PostgreSQL (پیش‌فرض سبک و سریع):
docker compose -f deploy/docker-compose.yml --profile postgres up -d
۲. اجرای با Microsoft SQL Server 2022:
docker compose -f deploy/docker-compose.yml --profile mssql up -d
۳. اجرای با Oracle Database 21c XE:
docker compose -f deploy/docker-compose.yml --profile oracle up -d
