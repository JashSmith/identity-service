## قرارداد نوشتن مستندات

- مستندات فارسی و راست‌به‌چپ است. خط، بند یا سرتیتری که با کلمه لاتین یا کد شروع می‌شود، بعد از نشانه Markdown یک نویسه RLM (U+200F) دارد.
- به جای فهرست خودکار GitLab، فهرست مطالب دستی نوشته می‌شود و هر پیوند آن باید به یک سرتیتر برسد.
- نمودارها با Mermaid نوشته می‌شوند. GitLab آن‌ها را نمایش می‌دهد؛ برای پیش‌نمایش در VS Code افزونه «Markdown Preview Mermaid Support» لازم است.
- پیش از ثبت تغییرات، این دستور را اجرا کنید؛ RLMهای جاافتاده را اضافه می‌کند و پیوندهای فهرست را بررسی می‌کند:

```bash
python scripts/check-docs.py --fix
```
